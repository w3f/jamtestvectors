This directory contains integration tests for the gas cost model, using a cut-down version of the test vector
format with only the `name`, `program` and `block-gas-costs` keys.

The `doom.json` testcase is distributed under GPL-2.0, with the source code available here: https://github.com/koute/polkadoom

The `prime-sieve.json` testcase is distributed under the 3-Clause BSD license, with the source code available here: https://github.com/paritytech/polkavm/tree/master/guest-programs/bench-prime-sieve

The `pinky.json` testcase is distributed under the CC0 1.0 Universal license.
